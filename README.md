hamzaaltaf-799.github.io

Personal portfolio site for Hamza Altaf — Computer Science (Cybersecurity) student at Brunel University London.

Live: https://hamzaaltaf-799.github.io

Overview

A single-page portfolio built to support software engineering, cybersecurity, and graduate job applications. Sections: Profile, About, Experience, Projects, Certifications, and Contact, with a downloadable/viewable CV.

Tech stack

Plain HTML, CSS, and JavaScript — no framework, no build step. Kept deliberately simple so the site deploys directly via GitHub Pages with zero build tooling.
